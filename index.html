Private personal assistant

This assistant is private and intended only for its owner. It is not a service for other users and has no public sign-up.

With the owner's permission, it works with Gmail messages, personal calendar events, and selected files in Google Drive to help organize everyday tasks and information.

Google content is used only to run the assistant, including processing by the AI and messaging services that operate it. It is never sold, made public, or shared for unrelated purposes.
